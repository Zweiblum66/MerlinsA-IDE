Launch the project start wizard to scope and set up a new project. The wizard runs through 8 steps:

1. **Project Vision** — What are you building? Who is the target user? What problem does it solve?
2. **Scope Definition** — AI suggests core features, nice-to-haves, and out-of-scope items
3. **Tech Stack** — Select frontend, backend, database, and auth technologies
4. **Architecture** — Choose: monolith, frontend+API, microservices, or serverless
5. **Work Breakdown** — AI generates epics, user stories, and tasks with story points
6. **Sprint Planning** — Set sprint duration, allocate stories to sprints
7. **Risk Assessment** — Identify technical, dependency, and complexity risks
8. **Project Generation** — Scaffold project, init git, populate backlog

Ask the user for input at each step. Use AI to generate suggestions they can refine.
