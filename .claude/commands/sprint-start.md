Start a new sprint for the project. Steps:
1. Review the current product backlog for prioritized user stories
2. Select stories for the sprint based on team velocity
3. Break selected stories into tasks with clear scope files
4. Assign tasks to appropriate agents (developer, qa-engineer, devops-engineer)
5. Set the sprint goal and token budget
6. Transition the sprint to IN_PROGRESS

Use the scrum-master agent to orchestrate this process.
